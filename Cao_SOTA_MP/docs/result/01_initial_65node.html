一、关于 α 参数的说明

α 是 deadline 的松紧程度系数，不是预算。公式：

τ = τ₁ + α · (τ₂ - τ₁)
  • τ₁ = 某条路径的最短行程时间（最快一次能多快到）
  • τ₂ = 所有路径中"最大行程时间最小"的值（最坏情况下最好的路径）
  • α = 0.5 → deadline很紧（只给一半余量，容易迟到，问题更难）
  • α = 0.9 → deadline很松（给90%余量，大概率准时，问题更简单）

α越小，各方法的差异越大——因为在紧deadline下，选错路的代价更高。

三、枚举优化方案

问题

论文用枚举所有路径来获取ground-truth。但65节点图的路径数是指数级的，枚举不可行。

解决方案: 用ILP本身作为ground-truth

论文已经数学证明了ILP是精确解(充要条件证明)。因此：

  • ILP的输出 = ground-truth最优路径
  • 其他方法的"准确率" = 是否达到了ILP相同的准时概率
  • 无需枚举，直接用ILP结果作为参考基准

这个方案在小图上已通过枚举交叉验证(10节点图，ILP与枚举结果完全一致)。

额外保护措施: 配置中可开启 enumerate_ground_truth: true，当路径数 < 5000 时自动枚举验证ILP结果。

四、与论文结果对比分析

指标论文结果我们的结果差异原因
ILP准确率100%100%完全一致
MILP准确率70-80%97.3%N=100区分度不如N=500
Dijkstra准确率60-70%96.5%同上
ILP计算时间0.32s (CPLEX)0.10s (CBC, N=100)N小所以更快
ILP > MILP > Dijkstra是是 (趋势一致)—
为什么MILP/Dijkstra准确率比论文高？

根本原因: 样本数N=100太少。
N越小，不同路径的"迟到次数"差异越小(离散化粒度粗)，更容易"碰巧"选对。
例如: N=100时，准时概率只能取 0%, 1%, 2%, ..., 100% 这101个值。
N=500时，粒度是0.2%，能区分更细微的差异，MILP更容易选错。

验证方法: 用CPLEX或Gurobi(学术免费)跑N=500实验，预期MILP准确率会降到论文水平。
