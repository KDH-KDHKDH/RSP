1.3 MILP 模型验证

min Σᵢ pᵢ — ℓ₁范数最小化正确
pᵢ ≥ Wᵢ'x - τ, pᵢ ≥ 0 — 约束正确（pᵢ 是连续变量，不要求 binary）
x ∈ {0,1}, p ∈ R₊ — 变量域正确（500个连续变量替换 ιᵢ）

6.2 设计限制（非错误）

  • 候选路径启发式: generate_candidate_paths 不能保证找到全局 minimax 路径。对大图 (587节点) 这是必要的近似，但 T_max/T_min 可能稍微偏离真实值。
  • 独立边假设: 每条边的行程时间独立采样（人工路网和北京模拟都是）。真实路网中相邻路段的时间存在相关性，但论文也未建模此相关性。
  • SCIP 求解器上限: 587节点 ILP 平均 22s，最大 120s (hit limit)。更大路网 (~1000+节点) 可能不可行。
  • 单种子评估: 仅有 seed=42 的完整实验。缺少多种子统计（均值 ± 标准差），结论的统计显著性有限。

准确率差异分析：
论文使用不同的网络拓扑、行程时间分布参数、deadline 参数 α 的精确定义，以及可能不同的候选路径生成策略。 此外论文未公开 deadline 计算的具体参数（α 范围和 τ₁/τ₂ 的精确定义）。 我们的 Dijkstra 路径匹配 (75.2%) 高于论文 (60-70%)，可能是因为：(1) 不同的随机图拓扑结构， (2) 论文可能使用更大的方差或不同的分布族。tie-aware 准确率在论文中没有对应指标，不可直接比较。
