8. 结论

Phase 8 审计修复验证成功。新指标系统工作正常，与旧结果一致。 核心准确率指标不变（ILP 100%, Dijkstra 75.2%, MILP 63.7%）， 新增的 tie_aware_accuracy 提供了更细致的评估视角。

主要发现

  1. 路径匹配准确率维持不变：ILP 100%, Dijkstra 75.2%, MILP 63.7%，与报告 06 完全一致，验证了代码修改未引入回归
  2. tie_aware_accuracy 反转了 MILP/Dijkstra 排名：MILP (90.2%) > Dijkstra (88.3%)。 MILP 的路径虽不同但准时概率更接近 ILP 最优解，用严格路径匹配评估会低估 MILP 的实际效果
  3. objective_gap < 0.001：两种基线的准时概率几乎等同 ILP，说明问题实例存在多个"几乎最优"的路径
  4. ILP 求解时间 0.338s，与论文 CPLEX 0.32s 持平，Tight Big-M 策略有效
  5. α 趋势一致：紧 deadline → 高准确率，松 deadline → 低准确率，与旧报告一致
  6. MILP < Dijkstra 仅 7% 案例，且差距在采样误差范围内
