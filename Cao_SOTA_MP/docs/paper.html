论文精读：准时问题的精确解法

原文: An Accurate Solution to the Cardinality-Based Punctuality Problem
作者: Zhiguang Cao, Yaoxin Wu, Akshay Rao 等
期刊: IEEE Intelligent Transportation Systems Magazine, Winter 2020
机构: 广东工业大学 / 南洋理工大学 / BMW@NTU
一句话总结：给定一张路网和历史行程时间数据，本文提出了一种精确找到"准时概率最大的路径"的方法——把问题建模为整数线性规划(ILP)，用现成求解器即可得到最优解。

一、这篇论文在解决什么问题？

生活场景

你要赶早上9点的飞机，从家到机场有好几条路。每条路的通行时间每天都不一样（堵车、天气等）。你想问导航："哪条路让我准时到达的概率最大？"

学术表述

这就是随机最短路径(SSP)中的准时问题(Punctuality Problem)：在交通时间不确定的路网中，找到一条路径，使得在给定截止时间(deadline)前到达目的地的概率最大。

为什么现有方法不够好？

方法思路问题
Dijkstra最短路走平均时间最短的路没考虑deadline，也没考虑时间波动
拟凸优化方法假设行程时间服从正态分布现实中分布未知，假设太强
ℓ₁范数松弛(MILP)数据驱动，无需分布假设只是近似解，可能找错路径
本文的贡献：在MILP近似解的基础上，通过引入二值指示变量，将问题精确转化为ILP，保证找到真正的最优路径。

二、问题是怎么建模的？

2.1 路网模型

把城市路网抽象为有向图 G = (V, L)：

  • V = 节点集（路口）
  • L = 边集（路段），共 |L| 条
  • o = 起点，d = 终点
  • x = 路径选择向量（x_j=1 表示走第j条路段）

2.2 原始目标

max P(总行程时间 ≤ deadline)
即：max Prob(w'x ≤ τ)
约束：x 构成从 o 到 d 的连通路径

其中 w 是随机的行程时间向量，τ 是用户设定的deadline。

2.3 数据驱动的转化（关键思想）

假设我们有 N 组历史行程时间数据（比如500天的记录）。那么"最大化准时概率"就等价于"最小化迟到次数"：

min 迟到次数 = min Card(C(x))

其中 C(x) = ([w₁'x - τ]⁺, [w₂'x - τ]⁺, ..., [wₙ'x - τ]⁺)

[·]⁺ = max(0, ·)，即只保留正值（迟到的部分）
Card(·) = 非零元素个数 = 迟到的次数
直觉理解：假设你走某条路500天，其中有20天迟到了，那这条路的"迟到次数"就是20。我们要找迟到次数最少的那条路。

三、三种求解方法对比

3.1 方法A：Dijkstra（最短路径基线）

思路：计算每条边的平均行程时间作为权重，用Dijkstra算法找最短路径。

缺陷：完全忽略了deadline和时间波动。平均最快的路不一定是准时概率最高的路。

类比：就像只看"平均成绩最高"来选学生，但忽略了稳定性——一个学生平均90分但波动大(60~120)，另一个平均85分但很稳定(80~90)，如果及格线是80分，后者更"靠谱"。

3.2 方法B：MILP近似解（ℓ₁范数松弛）

思路：把"最小化迟到次数"松弛为"最小化迟到总时长"。

min Σᵢ pᵢ （pᵢ = 第i次的迟到时长）
约束：pᵢ ≥ wᵢ'x - τ, pᵢ ≥ 0

缺陷：迟到时长 ≠ 迟到次数。看这个例子：

路径A：延迟向量 = [0, 3, 4, 0]

迟到总时长 = 7

迟到次数 = 2次 ✓ 更好

路径B：延迟向量 = [1, 2, 2, 1]

迟到总时长 = 6

迟到次数 = 4次 ✗ 更差

MILP会选路径B（总时长更小），但实际上路径A准时概率更高（4次中有2次准时 vs 0次准时）。

3.3 方法C：ILP精确解（本文核心）⭐

核心思想：不去管"迟到了多久"，只关心"迟到了没有"——用0/1变量标记每次是否迟到。

引入二值指示变量 ιᵢ ∈ {0, 1}：

  • ιᵢ = 1：第i次迟到了
  • ιᵢ = 0：第i次准时了
min Σᵢ ιᵢ （最小化迟到总次数）

约束：
① wᵢ'x - τ ≤ V · ιᵢ （若迟到，则ιᵢ必须为1）
② ιᵢ ∈ {0, 1}
③ Mx = b （x是合法路径）
④ x ∈ {0, 1}

V 是一个很大的数（Big-M），确保：

  • 当 wᵢ'x > τ（迟到）时：左边为正，ιᵢ 必须为1才能满足约束
  • 当 wᵢ'x ≤ τ（准时）时：左边为负/零，约束自动满足；但目标函数在最小化，所以ιᵢ会被压到0
为什么这是精确解？
Σιᵢ 精确等于迟到次数 Card(C(x))。论文给出了严格的充分必要条件证明：ILP的最优解 ⟺ 原始基数最小化问题的最优解。

四、ILP的标准形式（给求解器吃的）

把上面的模型整理成求解器能直接处理的标准ILP格式：

决策变量：z = [x₁, ..., x_{|L|}, ι₁, ..., ιₙ]' （共 |L|+N 个0-1变量）

目标：min f'z
f = [0, ..., 0, 1, ..., 1]'
←|L|个→ ←N个→

不等式约束：Az ≤ B
A 的第i行 = [Wᵢ₁, Wᵢ₂, ..., Wᵢ|L|, 0, ..., -V, ..., 0]
↑第i个ι位置
B = [τ, τ, ..., τ]' （N个τ）

等式约束：M·x = b （流守恒，保证路径连通）

变量界：0 ≤ z ≤ 1，z为整数

节点-弧关联矩阵 M 怎么构建？

M 是 |V|×|L| 的矩阵，描述图的拓扑：

  • 如果边 j 从节点 v 出发：M[v, j] = +1
  • 如果边 j 到达节点 v：M[v, j] = -1
  • 否则：M[v, j] = 0

OD向量 b：起点位置为+1，终点位置为-1，其余为0。

物理含义：Mx = b 保证了"流入 = 流出"（除了起终点），即x描述的是一条从o到d的连通路径。

五、实验结果

5.1 实验设置

两个测试场景：

  1. 人工路网：65个节点、123条边，行程时间随机生成
  2. 北京路网：362个节点、528条边，30000+出租车GPS真实数据

Deadline设定：τ = τ₁ + α·(τ₂ - τ₁)，α越小deadline越紧

验证方式：枚举所有路径找到真实最优解(ground-truth)，看各方法是否能找到它

六、方法的优缺点

✓ 优点

  • 无需假设行程时间的概率分布
  • 无需建立路段间的相关性模型
  • 数据驱动，直接用历史数据
  • 理论保证精确最优
  • 天然支持时间依赖（用对应时段数据即可）

✗ 局限

  • ILP最坏复杂度为指数级
  • 不适用于大规模路网（数千节点以上）
  • 需要足够多的历史行程时间样本
  • 枚举验证在大图上不可行

七、对复现的启示

我们需要实现什么？

  1. 图建模模块：构建有向图、关联矩阵M、OD向量b
  2. ILP求解器：构建并求解上述ILP模型（用PuLP + CBC/GLPK）
  3. MILP求解器：作为对比基线
  4. Dijkstra求解器：作为对比基线
  5. 数据生成器：生成人工路网和模拟行程时间
  6. 评估框架：计算准确率、准时概率、运行时间
核心公式速查：

准时概率 = 1 - (迟到次数 / 样本总数) = 1 - Σιᵢ* / N

Deadline = τ₁ + α·(τ₂ - τ₁)，其中 α ∈ {0.5, 0.6, 0.7, 0.8, 0.9}

准确率 = 找到真实最优路径的比例
